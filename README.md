# tomholford Homebrew tap

```sh
brew install tomholford/tap/gonetia
brew install tomholford/tap/remiterm
```

Casks are published here by [GoReleaser](https://goreleaser.com/) when the source repos are tagged:

- [gonetia](https://github.com/tomholford/gonetia) — generate Urbit planet names issuable from a star
- [remiterm](https://github.com/tomholford/remiterm) — RemiliaNET global chat in your terminal
